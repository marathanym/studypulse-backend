# StudyPulse Backend

## Project

This is the backend for the StudyPulse project.

## General Rules

- Use Python for backend development.
- Use FastAPI for the API.
- Keep the code simple and readable.
- Prefer small, focused modules and functions.
- Do not add unnecessary dependencies.
- Do not modify unrelated files.

## API Rules

- Use clear REST-style endpoints.
- Validate incoming request data.
- Return clear and consistent JSON responses.
- Handle errors explicitly.

## Testing

- Add tests for new API functionality.
- Run tests before considering a feature complete.

## Git

- Do not work directly on `main` for feature development.
- Use a separate branch for each feature or significant change.
- Make small, meaningful commits.
- Do not commit secrets, API keys, passwords, or `.env` files.
